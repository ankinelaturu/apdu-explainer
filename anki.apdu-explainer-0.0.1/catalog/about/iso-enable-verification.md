ENABLE VERIFICATION REQUIREMENT is the inverse of DISABLE: the named reference must be verified again before protected operations.

## Which reference (P2)

P2 is the same encoding as VERIFY. You usually need admin / PW3 (or the PIN itself) already verified.

## Status words you will see

| SW | Meaning |
|----|---------|
| `90 00` | Enabled |
| `6982` | Not allowed |
| `6A 81` | Function not supported |
