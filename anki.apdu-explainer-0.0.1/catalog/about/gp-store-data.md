STORE DATA personalizes an application or SSD. Used after INSTALL [for personalization] or against a selected app.

## Block number and format (P1-P2)

P1/P2 encode block number, last-block, and whether data is DGI-formatted or TLV.

## Status words you will see

| SW | Meaning |
|----|---------|
| `90 00` | Stored |
| `6A 80` | Bad DGI/TLV |
| `6982` | No SM / not allowed |
